# Hand model source

Source project: WebXR Input Profiles, Immersive Web Community Group.

- https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets/profiles/generic-hand
- https://github.com/immersive-web/webxr-input-profiles/blob/main/packages/assets/LICENSE.md

The left.glb and right.glb assets were downloaded from that directory on 2026-09-09. They are used under the asset package's MIT license, preserved in ASSET-LICENSE.txt. LICENSE.md preserves the repository-level license notice.

The application adapts the source at runtime: gentle finger flexion, thumb orientation, surface smoothing, skin shading, and separate nail shells fitted to the posed hand. These adapted meshes are used for the manicure preview, without WebXR hardware or camera access.
