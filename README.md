# 甲间 · Jiajian Nail Atelier

一个可以自己搭配颜色、甲形、图案和饰品的美甲设计实验。保留电脑工作台，以及光感探索和手机外框预览两个阶段的成果，供学习、改造和继续开发。

**状态：实验项目，原产品方向已停止推进。** 开源保留已有成果，不代表已完成商业产品验证，也不承诺持续维护。

## 能做什么

- 为单指、五指或十指搭配颜色、甲形、图案和饰品。
- 查看设计、生成灵感、保存作品和导出作品图。
- 在预览版探索猫眼、光泽、材质效果及手机尺寸下的工作台。
- 使用默认手部素材查看示意，不必先上传自己的照片。

这些是设计和效果示意，**不保证实物颜色、真实贴合或美甲制作效果**。不包含商品下单、支付、多人账号或生产运营服务。

## 先选一个版本

| 目录 | 用途 | 如何保存 |
|---|---|---|
| [effect-preview](effect-preview/README.md) | 快速体验、光感探索、手机外框预览；建议先从这里开始 | 当前浏览器中保存 |
| [workbench](workbench/README.md) | 早期完整本地设计工作台 | 本地数据库中保存草稿和作品 |

两个目录是独立快照，有意保留重复文件，方便分别启动。预览版的手机页面是在手机外框内展示可操作的工作台，不是后来重写的手机试色产品。

## 最快开始：预览版

安装 Node.js 22.12 或以上版本，在终端运行：

```sh
git clone https://github.com/laizhihui874-cmd/jiajian.git
cd jiajian/effect-preview
npm ci
npm run dev:workspace
```

- 手机外框预览：http://127.0.0.1:4321/mobile-preview.html
- 电脑工作台：http://127.0.0.1:4321/

此入口不需要数据库或图片生成服务。清除浏览器数据会失去本地保存内容，重要作品请导出留存。

## 本地工作台

需要 Node.js 22.12+ 和已启动的 Docker：

```sh
cd workbench
npm ci
npm run setup
npm run db:up
npm run dev
```

打开 http://127.0.0.1:4320/ 。`setup` 自动生成本机使用的随机密码，已有设置不会被覆盖。作品由本地数据库保存；停止使用时运行 `npm run db:stop`，不会删除作品。

## 检查与构建

分别进入两个目录执行 `npm test`、`npm run build`、`npm run lint`。
预览版如需构建不依赖数据库的页面，执行 `npm run build:workspace` 后 `npm run preview -- --host 127.0.0.1`。

## 使用边界

- 本项目默认只在本机访问，没有完整的公网账号和权限管理，请勿直接作为公共多用户服务部署。
- 猫眼、材质、图案和手部展示仍属于实验效果；不同画面和导出结果可能存在差别。
- 没有附带开发者的个人草稿、数据库、密码、日志、内部讨论或竞品项目。
- 未完成所有真实手机、浏览器和美甲实物的验证。原有检查警告和未完成方向不会被描述成已交付能力。
